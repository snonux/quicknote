Quicknote edits a folder of plain Markdown files. Point it at any folder, for example one Syncthing keeps in sync with your computer, and every .md and .markdown file in it and its subfolders shows up in a file tree.

<ul>
<li><b>File tree</b> of the notes folder, folders first; hidden folders such as .git or .obsidian are skipped.</li>
<li><b>Fuzzy finder</b>: type a few letters of a note's path to jump to it.</li>
<li><b>Raw editor</b> for the Markdown source exactly as it is on disk.</li>
<li><b>WYSIWYG editor</b> that shows headings, bold, italics, lists, tasks, quotes, links and code formatted as you type, with a formatting toolbar. It edits the same Markdown text, so switching editors never reformats a note.</li>
<li>Create, rename, move and delete notes. Saving asks before overwriting a note that changed on disk in the meantime.</li>
<li>Use the Android folder picker for a notes vault without broad storage permission, or type a path.</li>
</ul>

Quicknote has no network access at all: no accounts, no sync service, no telemetry. Your notes are just files.
